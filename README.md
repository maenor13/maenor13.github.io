# Site — Masculinisme et manosphère

Fichiers :
- index.html : présentation de l'essai, auteur, méthode, arguments et apport à l'exploration digitale
- analyse.html : analyse des masculinistes, hiérarchies, exemple TikTok et citations
- limites.html : limites méthodologiques et ressources externes
- style.css : tout le CSS (aucun style inline n'est utilisé)
- script.js : interactions et animations, avec commentaires en français

Ouvrir `index.html` dans un navigateur.
